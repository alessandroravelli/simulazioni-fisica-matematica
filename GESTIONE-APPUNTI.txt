GESTIONE APPUNTI (OBSIDIAN + QUARTZ)
=====================================

La sezione "Appunti" del sito (indirizzo /appunti/) è generata a partire
da normali file markdown, scritti con Obsidian. Lo strumento che li
trasforma in pagine web, con grafo dei collegamenti, ricerca e link
entranti, si chiama Quartz e sta nella cartella appunti/ del progetto.

Tu lavori SOLO dentro appunti/content: è il tuo "vault" di Obsidian.
Tutto il resto di appunti/ è Quartz e non va toccato.

Gli appunti sono protetti dalla stessa password del resto del sito.


1) APRIRE GLI APPUNTI IN OBSIDIAN (una volta sola)
---------------------------------------------------------------------
In Obsidian: "Apri cartella come vault" e scegli

  /Users/alessandroravelli/Documents/SAFA_documenti/sito_web/appunti/content

Poi in Impostazioni:
  - File e link → "Formato dei nuovi link": "Percorso più breve
    possibile"; "Usa [[Wikilink]]": attivo.
  - File e link → "Posizione predefinita per i nuovi allegati":
    "Stessa cartella del file corrente".
  - Plugin principali → Template: attivo, con cartella "templates".

La cartella templates/ contiene due modelli pronti ("Simulazione" e
"Dispensa PDF"): non viene pubblicata sul sito.


2) SCRIVERE UNA NOTA
---------------------------------------------------------------------
Crea un file .md nella cartella dell'argomento (es. Fisica/Onde/).
In cima puoi mettere un'intestazione così (facoltativa):

  ---
  title: Titolo della nota
  description: Una riga di riassunto.
  tags:
    - fisica
  ---

- Collegamento a un'altra nota:  [[Moto armonico]]
  oppure con testo diverso:      [[Moto armonico|moto armonico]]
- Formule come in LaTeX:  $x = A\cos(\omega t)$  oppure su riga propria
  tra $$ e $$.
- Riquadri evidenziati:  > [!tip] Titolo   (anche note, warning,
  example...)

Il grafo e i "Link entranti" si aggiornano da soli in base ai [[...]].


3) COLLEGARE UNA SIMULAZIONE
---------------------------------------------------------------------
Usa il modello "Simulazione" (oppure copia dalla nota "Moto armonico").
Per le simulazioni serve SEMPRE l'indirizzo completo, che inizia con
https://simulazioni-fisica-matematica.alessandro-ravelli00.workers.dev/
(con un indirizzo che inizia solo con /esperimenti/... Quartz lo
trasformerebbe e il link non funzionerebbe).

Dentro Obsidian il riquadro della simulazione può restare vuoto: sul
sito invece funziona, perché lo studente ha già fatto il login.


4) AGGIUNGERE UNA DISPENSA IN PDF
---------------------------------------------------------------------
- Copia il PDF nella cartella dove vuoi la dispensa (es. Dispense/).
- Crea una nota accanto (modello "Dispensa PDF") e scrivi dentro

    ![[nome-del-file.pdf]]

  Il PDF compare incorporato nella pagina; nella nota puoi aggiungere
  collegamenti alle altre note e alle simulazioni.
- Ogni file deve pesare meno di 25 MB (limite di Cloudflare).

Quando poi vorrai riscrivere la dispensa in markdown, basta sostituire
la riga ![[...pdf]] con il testo: i collegamenti restano.


5) BOZZE NON PUBBLICATE
---------------------------------------------------------------------
- Per una nota non ancora pronta, aggiungi nell'intestazione
    draft: true
  Non compare sul sito, ma viene comunque salvata su GitHub.
- La cartella private/ invece non viene né pubblicata né salvata su
  GitHub (resta solo sul tuo computer: niente backup!).


6) PUBBLICARE
---------------------------------------------------------------------
Da Terminale, nella cartella del progetto:

  cd "/Users/alessandroravelli/Documents/SAFA_documenti/sito_web"
  git add appunti/content
  git commit -m "Appunti: descrizione della modifica"
  git push

Cloudflare ricostruisce gli appunti da solo: dopo 1-2 minuti sono online.
Se qualcosa non va (es. un errore nella build), il sito resta alla
versione precedente: non si rompe.


7) VEDERE IN ANTEPRIMA SUL COMPUTER (facoltativo)
---------------------------------------------------------------------
La prima volta:

  cd "/Users/alessandroravelli/Documents/SAFA_documenti/sito_web/appunti"
  npm ci

Poi, ogni volta:

  cd "/Users/alessandroravelli/Documents/SAFA_documenti/sito_web/appunti"
  npx quartz build --serve

e apri http://localhost:8080 nel browser (si aggiorna da solo mentre
scrivi). Per fermarlo: Ctrl+C nel Terminale.
